# UI Contract: Maintenance Workflow Integration

## Asset Detail Page

**Route**: `/assets/:id`

**New / updated sections**:

### Active Incidents Widget

- Lists open incidents (states in `IncidentStates.ActiveStates`).
- Columns: title, state, priority, reported date.
- Action: click row navigates to `/maintenance/incidents/:id`.

### Maintenance Orders Widget

- Lists orders linked to the asset.
- Columns: title, kind, state, scheduled dates.
- Action: click row navigates to `/maintenance/orders` with the order selected.

### Work Tasks Widget

- Lists tasks linked to the asset.
- Columns: title, state, assignee, due date.
- Action: click row navigates to `/maintenance/tasks` with the task selected.

### Preventive Plans Widget

- Lists plans targeting this asset or its template.
- Columns: name, next run, active flag.
- Action: click row navigates to `/maintenance/preventive-plans`.

## Incident Detail Page

**Route**: `/maintenance/incidents/:id`

**New / updated sections**:

### Generated Maintenance Order

- If a corrective order exists, show a card with: title, state, assigned employee, scheduled dates.
- Provide a direct link to `/maintenance/orders` with the order selected.
- Show a warning if the incident is in a terminal state but the order is still active (should not happen due to guards, but defensive UI).

### Child Tasks

- List tasks derived from the incident.
- Columns: title, state, assignee, due date.
- Allow creating a new task linked to this incident.

### Close Incident Action

- Disable the "Close" button if the guard detects active orders or open tasks.
- Show tooltip: "Cannot close while corrective work is pending."

## Maintenance Order Detail Page

**Route**: `/maintenance/orders` (detail side panel)

**New / updated sections**:

### State Actions

- Buttons: `Approve`, `Schedule`, `Start`, `Complete`, `Verify`, `Cancel`.
- Only enabled buttons correspond to valid transitions from the current state.
- `Start` moves the order to `in_progress` and child tasks to `in_progress`.
- `Complete` moves the order to `done`.
- `Verify` moves the order to `verified` and closes a linked corrective incident.

### Child Tasks

- List tasks with `MaintenanceOrderId == order.id`.
- Columns: title, state, assignee, due date.
- Show progress: `(done + cancelled) / total`.
- When all tasks are terminal, show a badge "Ready to complete".

### Related Links

- Asset link → `/assets/:assetId`.
- Incident link → `/maintenance/incidents/:incidentId` (if corrective).
- Preventive plan link → `/maintenance/preventive-plans` (if preventive).

## Preventive Plan Detail Page

**Route**: `/maintenance/preventive-plans` (detail side panel)

**New / updated sections**:

### Generated Work Items

- Two tabs: `Tasks` and `Orders`.
- Lists items generated by this plan with state and target asset.
- Items are clickable links.

### Execution Log

- Already exists; no change.
- New skip reasons related to active incidents/unverified orders should be readable in the `Message` column.

## Work Task Detail Page

**Route**: `/maintenance/tasks` (detail side panel)

**New / updated sections**:

### Related Parent

- Show the most specific parent as a clickable link:
  1. Maintenance order → `/maintenance/orders`
  2. Incident → `/maintenance/incidents/:id`
  3. Preventive plan → `/maintenance/preventive-plans`
  4. Asset → `/assets/:id`
- If `IsIndependent == true`, show "Independent task".
